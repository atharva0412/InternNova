# InternNova

Week 1 Assignment – HTML Fundamentals

This project covers the fundamentals of HTML5 through a series of practical tasks. The assignment focuses on creating structured and semantic webpages using HTML only, without CSS or JavaScript.

Tasks Included
Task 1: HTML Document Structure
Task 2: Text Formatting & Basic Elements
Task 3: Links, Images, Lists & Tables
Task 4: Student Registration Form
Task 5: Semantic HTML
Task 6: Mini HTML Project
Task 7: Reflection & Learning

Technologies Used
HTML5

Key Concepts Covered
HTML structure, text formatting, hyperlinks, images, lists, tables, forms, input types, semantic elements, and webpage organization.

Purpose
The assignment helped build a strong foundation in HTML and provided hands-on experience in creating structured static webpages from scratch.
